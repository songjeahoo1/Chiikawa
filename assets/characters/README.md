# 캐릭터 이미지

현재 사용자가 제공한 랏코·모몽가·시사·우사기·치이카와·카니·쿠리만쥬·하치와레·아노코·포셰트갑옷씨·라멘갑옷씨·노동갑옷씨 PNG를 `character-images.js`와 `character-updates.js`에 데이터 URI로 포함했습니다. 결과 화면과 도감에서 모두 사용합니다. 별도 이미지 서버나 OneDrive 경로를 요구하지 않습니다. 파일을 `assets/characters/`로 복사해 관리하려면 아래 설명대로 매핑 경로를 바꿀 수 있습니다.

이미지를 프로젝트에 복사하려면 파일을 이 폴더에 넣고 `characterImages` 설정을 `upgrade.js`에서 실제 파일명으로 수정하세요. 권장 파일명은 캐릭터 ID 기준 PNG이며, PNG/JPG/JPEG/WebP를 사용할 수 있습니다. 이미지 파일이 없거나 로딩에 실패하면 이름과 테마 색상이 대체 표시됩니다.

컴퓨터의 OneDrive 사진 폴더는 브라우저가 자동으로 탐색할 수 없습니다. 사이트의 “이미지 폴더 선택” 버튼을 눌러 폴더를 직접 지정하거나, 파일을 이 폴더로 복사하세요. 원본 이미지를 삭제하지 않습니다.
