# 너는 어떤 먼작귀?

한국어 비공식 팬메이드 성격 테스트입니다. HTML, CSS, JavaScript만으로 구성되며 서버나 API 키 없이 브라우저에서 점수를 계산합니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 일부 브라우저는 로컬 파일에서 공유/클립보드 권한을 제한할 수 있으며, 이 경우 현재 주소 복사 안내가 표시됩니다. 간단한 로컬 서버를 이용해도 됩니다.

## 파일 구성

- `index.html`: 화면 구조와 접근성 레이블
- `style.css`: 색상, 반응형 레이아웃, 모션 감소 설정
- `script.js`: 24문항, 캐릭터 프로필, 점수 계산, 결과/도감/공유/PNG 저장

## 채점 방식

각 문항은 두 개 성격 차원에 반영됩니다. 4개 답은 차원 방향으로 -1.5, -0.5, +0.5, +1.5점을 줍니다. 문항마다 방향이 다른 두 축을 선택해 24개 답을 모으고, 축별 관측 최솟값과 최댓값을 기준으로 0~100에 정규화합니다. 캐릭터 프로필과 사용자 점수 사이의 8차원 정규화 유클리드 거리를 계산하고 `100 × (1 - 거리)`로 유사도를 구합니다. 유사도 내림차순으로 1~3위를 정하며, 동점은 캐릭터 데이터에 선언된 순서를 사용합니다. 무작위 요소는 없습니다.

이 점수는 사이트 안에서 프로필을 비교한 값일 뿐, 심리학적 정확도나 진단을 의미하지 않습니다.

## 이미지 교체

기본 그래픽은 이모지와 CSS 색상 카드로 표시되며, 외부 캐릭터 이미지가 필요하지 않습니다. 적법하게 사용할 수 있는 이미지가 있다면 `assets/characters/` 폴더를 만들고 각 캐릭터 카드의 이모지 영역을 `<img>`로 교체할 수 있습니다. 이미지가 없을 때도 현재 대체 그래픽이 표시됩니다. 공식 이미지가 포함되어 있지 않습니다.

## 빠른 확인 방법

1. 시작 화면에서 시작을 누르고 24문항 모두 답합니다.
2. 이전 버튼으로 돌아가 답을 바꾼 뒤 결과가 반영되는지 확인합니다.
3. 결과의 1~3위, 8개 점수, 공유/PNG 저장, 다시 테스트, 캐릭터 도감을 확인합니다.
4. 모바일 폭으로 창을 줄여 답변 버튼과 결과 카드가 세로로 정렬되는지 확인합니다.

## 업데이트 기능

- 15, 25, 50, 100, 500문항 모드를 제공하며 기본 추천은 25문항입니다. 안내 소요 시간은 문항당 약 8초를 기준으로 한 초기 추정입니다.
- `upgrade.js`에서 핵심 24개 질문과 추가 상황 질문을 별도 데이터 구조로 구성합니다. `validateBank()`는 총 질문 수, 고유 ID, 질문 문구 중복, 보기 수를 확인하며 500문항 모드 시작 전 검증합니다.
- 모든 문항은 8개 성격 차원 중 2개에 명시된 보기별 가중치를 반영합니다. 축별 점수는 관측된 질문 수와 점수 범위를 사용해 0~100으로 정규화합니다.
- 500문항 진행 중 답변과 현재 위치를 브라우저 `localStorage`에 저장합니다. 새로고침 후 홈에서 이어서 하거나 저장을 삭제할 수 있습니다. 완료 시 저장 데이터는 지웁니다.
- 결과에는 모든 등록 캐릭터가 같은 거리 계산으로 정렬되어 나타납니다. 유사도는 테스트 내부 비교값입니다.
- 로컬 이미지 폴더를 자동으로 읽지 않습니다. 홈의 “캐릭터 이미지 폴더 선택”으로 직접 고르거나 적법하게 확보한 파일을 `assets/characters/`에 복사해 주세요. 이미지는 별도 `characterImages` 설정에서 연결합니다. 폴더 선택은 브라우저 메모리에만 유지되므로 새로고침하면 다시 선택해야 합니다.

## 검수 한계

이 실행 세션에서는 로컬 셸 및 브라우저 자동화 도구가 초기화 오류를 내 실제 페이지 동작을 실행 검수하지 못했습니다. `validateBank()`는 브라우저 개발자 콘솔에서 호출해 데이터 검증 결과를 확인할 수 있습니다. 이미지 폴더도 도구 오류로 파일 목록을 읽지 못했으므로 파일명을 임의로 가정해 연결하지 않았습니다.
